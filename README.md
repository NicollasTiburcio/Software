# Engenharia de Software

Acervo didático e guias de estudo cobrindo diferentes áreas da Computação, da arquitetura de hardware à programação, aos bancos de dados e à engenharia de software.

## Sobre o projeto

Este repositório reúne materiais didáticos em Markdown, organizados por disciplina. As apostilas apresentam os conteúdos de estudo e, quando disponíveis, há arquivos separados para atividades.

Para navegar pelos materiais, acesse o [site publicado pelo GitHub Pages](SITE_URL).

## Disciplinas disponíveis

- **Arquitetura e Organização de Computadores** *(em construção)*.
- **Banco de Dados** *(em construção)*.
- **História dos Computadores** *(em construção)*.
- **Linguagem de Programação — Python** *(em construção)*.
- **Lógica de Programação** — fundamentos de algoritmos e atividades.
- **Programação Orientada a Objetos** *(em construção)*.
